# QuickNote

Небольшой блокнот для macOS с плавающей кнопкой поверх окон и меню в строке macOS.

## Возможности

- Перетаскиваемая кнопка с превью последней созданной заметки.
- Несколько записей с локальным автосохранением.
- Экспорт в TXT (UTF-8) и PDF (A4, автоматические переносы и номера страниц).
- Светлая, тёмная и системная темы.
- Сохранение положения кнопки, размера и положения блокнота, ширины списка заметок и положения настроек.
- Закрытие блокнота сворачивает его в кнопку. Полный выход через меню **QN → Завершить QuickNote**.

## Требования и сборка

macOS 13+, Apple Silicon, Xcode или Command Line Tools с компилятором Swift, Python 3.

```sh
./build.sh
open QuickNote.app
```

Скрипт собирает приложение, генерирует иконку и ставит локальную ad-hoc подпись. Кэш находится в `.build/`. Приложение не нотариализовано Apple. При желании скопируйте `QuickNote.app` в «Программы».

## Управление

| Действие | Клавиши |
| --- | --- |
| Новая заметка | ⌘N |
| Сохранить | ⌘S |
| Экспорт TXT / PDF | ⌘E |
| Свернуть в кнопку | ⌘W |
| Настройки | ⌘, |
| Полный выход | ⌘Q |

Сочетания работают при активном приложении. Настройки также доступны через кнопку ⚙. Удаление записи требует подтверждения; корзины нет.

## Данные

Заметки хранятся локально в `~/Library/Application Support/QuickNote/notes.json`. Папка открывается через меню QN. Приложение не использует сеть. Настройки сохраняются в UserDefaults. Обновление приложения не удаляет заметки.

Кнопка отображается на рабочих столах и совместимых полноэкранных пространствах. Защищённые системные экраны macOS могут перекрывать её.

## Исходники

- `Source/main.swift` — интерфейс AppKit, заметки, настройки и хранение.
- `Source/PDFExporter.swift` — многостраничный экспорт Core Text.
- `Source/make-icon.swift` и `Source/package-icon.py` — генерация иконки.
- `Assets/QuickNote.icns` — иконка приложения.

## Проверки

Проверены сборка и локальная подпись, сохранение нескольких заметок с кириллицей и emoji, защита повреждённого хранилища от перезаписи. Для PDF проверены 150 строк на пяти страницах, извлечение всего текста и пустая заметка. Полная интерактивная проверка интерфейса не выполнена.
